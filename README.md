# A Diwali e-bouquet for Ladoo ❤️

A small Diwali surprise in three pages that ends with a bouquet of pink roses that never wilt.

| Page | What happens |
|---|---|
| `index.html`: Surprise | A dark room with five diyas. Tap each one to light it (or light them all at once). Then the quote appears, followed by the letter "Hey Ladoo! ❤️". |
| `gift.html`: Your Gift | A wrapped gift box that opens to "Because you deserve little surprises and big smiles.", plus a greeting card that opens like a book. |
| `celebrate.html`: Celebrate | A marigold toran, a rangoli, a ring of diyas, fireworks wherever you tap, the final message, and then **the e-bouquet**: "Hey Ladoo · Open your flowers", pink roses blooming, falling petals and the "Dear Ladoo" letter. "Celebrate Again ✨" starts over. |

Every page also has optional music (the little bars icon in the header), golden sparkles and soft page transitions.

Plain HTML, CSS and JS with no build step. Open `index.html`, or host the folder on GitHub Pages.
